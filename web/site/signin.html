A code from whoever invited you. It works once, and it expires 24 hours after it was made.

Forgotten which device holds your passkey? Passkeys sync through iCloud Keychain or Google Password Manager, so try another device signed into the same account. If that fails, ask whoever invited you for a fresh code — there is no automated reset, because we hold no email address to send one to.
